# Spec-Kit Clinical Requirements: ShasthoSetu AI v2.0

## Functional Requirements
- **FR-01 (Bilingual Triage)**: System shall support real-time audio and text inputs in Bengali and English, providing grounded triage recommendations with source citations.
- **FR-02 (Emergency 999)**: System shall detect red-flag symptoms with zero false-negative tolerance, triggering direct 999 hotline UI.
- **FR-03 (Prescription Gate)**: System shall enforce HTTP 422 human verification gate for ambiguous handwritten prescriptions.
- **FR-04 (Blood Matching)**: System shall provide real-time geo-radius matching (5/10/20 km) across 8 administrative divisions of Bangladesh with phone number privacy.
- **FR-05 (MCP Interop)**: System shall expose clinical guideline, directory, and care record tools over standard Model Context Protocol.
